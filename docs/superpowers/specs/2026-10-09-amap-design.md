# 高德地图与选点

按用户已确认方案实施。高德 JS API 2.0 按需加载，安全密钥仅服务端配置，serviceHost 使用同源 /_AMapService，白名单代理固定高德上游。无配置时不请求 SDK，显示明确提示并保留原列表/手动坐标输入。

新增 MapLocation 类型 {longitude,latitude,address?,accuracy?,coordinateSystem:'GCJ02'}。管理员与用户共用 LocationPicker，点击/拖动标记/搜索/主动定位形成临时选点，显式确认才向父组件提交；取消不改表单。定位使用高德 Geolocation convert:true；原生 GPS 不直接用于距离查询。精度圈由返回 accuracy 展示，过粗定位需用户确认。异步搜索/地址回查/定位均防旧响应覆盖新操作，地图卸载销毁。

用户位置不写数据库、不持续跟踪；地图拖动不改变起点。空间地图与列表使用同一接口结果，选择标记显示 Vue 渲染摘要与详情入口，避免 HTML 注入；距离明确为直线距离。地图不可用不阻止业务。

V6 为 study_space 增加 coordinate_system，既有非演示坐标标为 UNKNOWN，需要管理员确认；仅原 V2 的十条名称及原坐标完全匹配的合成演示数据标为 GCJ02，仍注明非真实校园。后续输入按 GCJ02 写入，拒绝声明 WGS84/BD09。未知坐标不参与距离推荐、不绘制地图，管理列表保留并提示确认。无需猜测转换未知坐标。

验收：加载失败/重试、未配置提示；确认取消；旧异步结果拒绝；地图标记点击及更新清理；坐标校验和迁移；代理白名单、鉴权、不泄漏安全密钥；前端测试构建与后端回归。没有真实 Key 时明确保留高德在线及实机定位验收限制。
