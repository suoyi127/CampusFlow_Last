# 首次集成设计

依据根目录外的《学习空间推荐系统三人开发计划》和《学习空间推荐系统需求文档》1.0，落实 D1—D5 首次集成。已有项目规范授权常规技术选择自主执行。

采用计划已选择的单仓库、单 Spring Boot 后端、Vue 3 手机适配网页和 MySQL。按功能划分 auth、space、simulation、status、recommendation、system，review 后续实现。相比仅搭空框架，本批交付可以演示登录到动态空间查询的闭环；相比一次实现全部功能，先验证三人后续共用的接口与数据模型。

后端使用 Java 21 编译目标、Spring Security 会话认证、CSRF、MyBatis-Plus 和 Flyway。默认 mysql 配置通过环境变量连接数据库；local 配置使用文件 H2，test 使用内存 H2，仅用于快速演示与测试，不替代 MySQL 交付验证。初始化十个不同设施和开放时间的空间；演示账号仅在明确启用演示初始化时创建，保存 BCrypt 摘要。

三角色 USER、DATA_ADMIN、SERVER_ADMIN 不继承管理权限。全部角色可以查询空间；只有 DATA_ADMIN 维护空间；只有 SERVER_ADMIN 控制本批模拟的启动暂停。登录退出后更新 CSRF 令牌。统一错误包含 code、message、timestamp；不向客户端返回数据库或堆栈。

模拟由后端单一定时任务运行，数据库保存运行编号、虚拟到访、人数快照和设备采样。事务锁定空间，维护人数容量边界，停用或关闭时结束在场到访，不生成新的读数。状态查询分别返回人数和噪声时间；30 秒过期，60 秒有效读数中位数作为典型噪声。设备离线与过期显示未知，不冒充空闲或安静。

前端具有登录、空间列表、详情、空间管理与服务器概况入口，每五秒查询一次服务器状态，路由离开时清理轮询。请求失败保留筛选条件，按指标更新时间降级过期显示，提供重试。设施多选采用同时满足，列表提供基础筛选与稳定排序，不用客户端随机数制造状态。

最小验证覆盖会话及 CSRF、401/403、十空间初始化、空间维护、容量与模拟边界、独立时间及过期、噪声中位数。前端执行类型检查与构建。记录实际 MySQL 验证情况，未验证的环境不宣称通过。

后续 D6—D11 完成评价与审核、系统账号配置、场景与异常记录管理；本批不提供未实现功能的假成功界面。
