# C04 与 A05 管理闭环

用户确认仅 C04 + A05。沿用会话认证、三角色隔离、现有数据库与单体模块，不引入 C05 场景、重置或异常管理。

账号：服务器管理员分页查询、创建、修改角色及启停。用户名唯一且不可改名；密码仅创建时传入，BCrypt，不返回或记录明文。每次有效角色或启停变更递增 version，旧会话下一次访问 API 返回 401；重新启用不恢复旧会话。并发管理通过固定锁顺序序列化并核对 expectedVersion，禁止使启用 SERVER_ADMIN 数量变为 0。

配置：单行完整配置，version 防止旧表单覆盖。simulationSeconds 2—60，validitySeconds 5—300，noiseWindowSeconds 5—600；validitySeconds 至少为 simulationSeconds 的两倍，noiseWindowSeconds 至少为 validitySeconds。distanceWeight、quietWeight、freeWeight、facilityWeight 为有限 0—1 数值且总和为 1。默认 5/30/60 与 .30/.30/.25/.15。持久化后每次业务操作读取配置；模拟调度按新周期、状态按新时效窗口、推荐按新权重计算；前端仍每 5 秒轮询。

日志：只读分页，按 actor、action、起止上海日期筛选，时间 UTC 输出；成功账号与配置操作在同一事务记录。日志不包含密码，无删除接口。

A05：保留服务器概况和暂停继续，增加账号、配置、日志页面与导航。轮询不覆盖编辑表单，冲突显示重新加载入口；失败保留输入。场景与重置清楚标为 C05 后续范围，不伪造可用功能。

验收：权限、CSRF、最后管理员、重复用户名、禁用及角色变更旧会话、重新启用不复活旧会话、版本冲突、配置范围与关系、运行参数实际生效、日志分页过滤、构建及前后端真实请求。业务数据结构与接口文档同步更新。
